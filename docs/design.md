# 四隅织途：玩法设计

## 故事与流程
四隅织机失去四束线，桃园、烛糖、回声、层桥四方散开。玩家扮演线轴邮差，把各地遗落的织箱推回线座，使四方重新相连。基调轻盈、安静、偶有俏皮。流程为标题 → 四向中心 → 自选世界 → 各五十道谜题 → 中心交汇四题 → 织机复原。四个世界从开始都能访问，各自内部循序解锁。

## 核心规则
四方向离散移动，每次可推动一个箱子，不可拉箱，不可连续推动一串箱子。所有箱子停在目标上完成关卡。移动具有短促、可预测的演出，逻辑与动画解耦，不因帧率改变结果。
无限撤销；重置也作为历史状态，可撤销重置。关卡进度持久保存，可回访已完成关卡。撤销/重置不产生惩罚。
键盘 WASD / 方向键移动，Z 撤销，R 重置，Esc 返回/暂停；界面同时提供按钮。具体快捷键以实装界面和 README 为准。

## 四方机制
1. 桃园：滑行地面仅作用于箱子。推动进入后沿原方向滑行，在第一块非滑行地面或障碍前停下。箱子可用作挡块。
2. 烛糖：配对泉眼作用于箱子。进入后立即到达配对出口；出口不可占据则整次推动失败，不连锁回传。
3. 回声：单向根门限定进入方向，对玩家、箱子都生效。强调绕路与站位而非反应速度。
4. 层桥：箱子压住任一踏板，桥门打开。是否能进入门使用动作前的开闭状态；动作结束后不允许任何占据者落在关闭的桥门中，故最后一只压板箱不能造成非法关门。

## 关卡与难度
V2 为每世界 10 章 × 5 题，共 200 道主线谜题，随后保留 4 道双机制交汇奖励题，共 204 关。章节从教学、取位、通路与暂存逐步推进至多箱协作和综合挑战。每章只显示 5 个旅程节点，完成度与解锁从数据读取。实际关卡清单、最少推动数、最少步数、展开状态数和解答见 levels_validation.md 及 assets/levels.json。
求解器使用与运行时一致的规则，验证最短推动数并以步数破同分；验证解答回放，区分搜索预算耗尽与不可解。教学题允许简单，但后续题应有真正的站位决策，不能只靠长走廊增加步数。
难度指标是辅助而非“好谜题”的证明。检查机制是否被使用、目标是否存在明显捷径及无意义移动；对组合关卡做规则一致性测试。

## 不做什么
不做计时、战斗、付费、联网、随机永久死局，不加入未经教学的隐藏操作。不以数量代替教学、差异化与可解验证。景观表现高差，但核心解谜格点保持可读，层桥以景观地形与压力桥体现山城主题。
