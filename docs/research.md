# 研究要点与来源

研究日期：2026-10-23。已联网研究，不是离线猜测。此文区分「来源事实 / 画面观察」和「本项目推导」。官方商店六张截图已实际查看；仅作为外部临时研究，不进入工程、资产或交付包。没有下载或复用任何游戏资产、角色、音乐或关卡。

## 1. 《沉星之序》：借鉴组织与可读性，不复刻内容

### 来源事实
- 官方说明四个世界各有机制、角色与故事，随后系统交汇；允许玩家离开并返回挑战。
- 设计重点是规则逐步生长、组合产生新的问题，不是大量重复的箱子排列。
- 官方承认其基础作品与贡献者；本项目不移植这些作品的关卡、人物或对应机制组合。
- 来源：[官方 Steam 商店](https://store.steampowered.com/app/499170/Order_of_the_Sinking_Star/)；[发行商 Explore the Realm 介绍](https://www.arcgames.com/news/11583185)。后者搜索索引可读取概要，但正文是动态页面；不以其未读取部分作依据。

### 实际画面观察
- 高位斜俯视，能看到格面与平台侧厚；不靠近景镜头展示角色脸部。无法仅凭截图断言它使用正交投影或确定焦距。
- 地面有规则网格与装饰分区，建筑、植被、立柱在棋盘周边形成框景。落差、水和远景让小棋盘嵌入有纵深的世界。
- 亮色游戏区域与较暗、较冷的外围形成对比。暖粉庭院、青蓝水面、黄绿草台、紫色暗部互相衬托，并非一整屏同色。
- 角色在棋盘内比例较小，衣帽轮廓和身体颜色帮助辨认；交互物体的颜色和标记比外围细节更明确。
- 多场景统一于格尺度、石台边缘厚度、物件体量与光照质量。差异来自建筑密度、轮廓、植被、水域和高差，不只是换材质颜色。
- 观察入口：[官方媒体页](https://www.orderofthesinkingstar.com/en/media)；实际查看的是官方 Steam 商店提供的六张宣传截图，例如[庭院截图](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/499170/44bbf392f454a49aa304917d30befad7f2bad8e3/ss_44bbf392f454a49aa304917d30befad7f2bad8e3.1920x1080.jpg)。这些链接仅用于来源追溯。

### 本项目推导，不是对原作实现的断言
- 使用固定高位斜视、稳定格尺度、柔和大面积光源、倒角实体与清楚接触阴影，形成原创的精致玩具工坊感。原作本身比纯玩具更写实，不将“玩具感”冒充原作官方美术定义。
- 四方向入口明确，初期分别教一种空间规则，后期才少量交汇。不能照搬原作角色职业、镜像交换、光束机关及房间布局。
- 关卡应具有“先认识规则—改变原有直觉—组合验证”的递进；求解器证明可解只是底线，不能证明谜题一定有趣。还需检查最短路线、绕过机制的捷径、无意义步数、首次失败能否理解。

## 2. 上方：国风天宫

### 来源要点
- 故宫建筑以南北中轴、成组殿堂、左右辅翼和层层院落构成秩序；门、殿、楼、阁有不同轮廓和空间功能。
- 斗拱是梁柱之间层叠的承托构件；屋檐不应只画成一个漂浮三角形。这里只提炼结构语汇，不复制具体宫殿比例与纹饰。
- 来源：[故宫博物院建筑目录](https://www.dpm.org.cn/explore/buildings.html)；[香港故宫“紫禁万象”](https://www.hkpm.org.hk/en/exhibition/entering-the-forbidden-city-architecture-collection-and-heritage)；[台湾历史博物馆建筑展说明，斗拱与屋顶](https://event.culture.tw/userFiles/NMH/DownloadFile/01/40016/01/40016_02_432978.pdf)。

### 原创转译
- 结构：宽而轻的曲檐、短柱与简化三层托木、玉石台基、云端连廊；对称骨架配不对称云团。
- 材质 / 色彩：温润玉白、青绿釉瓦、少量朱砂和哑光金；不要一律耀眼金属。
- 光照 / 氛围：高明度奶油色天空、薄青阴影、软云层，让台阶和箱子落地清楚。
- 机制启发：风、云路或定向滑行体现“轻盈而有秩序”，用图形方向标识规则，不用装饰文字隐藏规则。

## 3. 下方：西方地狱地牢

### 来源要点
- 白塔的厚墙、塔楼、旋转楼梯、圆拱和石造承重感可提供地牢结构参考。
- Newark Castle 的官方遗产说明明确提到地下地牢和厚重筒拱。历史地牢不等同于幻想中的满地岩浆；地狱部分是本项目虚构。
- 来源：[Historic Royal Palaces：White Tower](https://www.hrp.org.uk/tower-of-london/whats-on/white-tower/)；[Historic England：Newark Castle](https://historicengland.org.uk/listing/the-list/list-entry/1196278/)。

### 原创转译
- 结构：短粗圆拱、块状砌石、炉口、粗链条、铜铆钉；以圆钝角和夸张小角生物消解恐怖。
- 材质 / 色彩：李子紫石、深蓝阴影、陶红、蜜橙余烬，铜色点缀。冷色地面保留亮度，不做黑糊一片。
- 光照 / 氛围：暗环境仍有柔和蓝紫填充，炉口暖光是局部焦点；避免红光覆盖所有交互物。
- 机制启发：温度、开关门或压力联动体现“有机关的锅炉地窖”；门的开闭必须立即可见、可撤销。

## 4. 左方：热带雨林

### 来源要点
- Kew 的教育资料区分超冠层、冠层、林下层和森林地表；雨林不只是相同高度的棕榈树。
- NSW 国家公园资料解释浅根、板根与树冠遮光；藤本向光生长。具体物种与地区不同，不能把所有雨林混称一种生态。
- 来源：[Kew：Biome infographic](https://endeavour.kew.org/sites/endeavour/files/documents/2024-06/Kew-KS2-PackYourBags-Biome-infographic.pdf)；[NSW：根系与板根](https://www.nationalparks.nsw.gov.au/~/media/E8073DC1918348D3AD95B4650C8FE915.ashx)；[NSW：林下日照](https://www.nationalparks.nsw.gov.au/-/media/visitor/files/pdf/education/rainforests-of-nsw/sun-and-shade-in-the-rainforest.pdf)。

### 原创转译
- 结构：少量大板根树、分层阔叶、曲藤、苔石、浅水。叶丛做成有主脉与弯曲面的组团，不以随机绿三角填满画面。
- 材质 / 色彩：深翡翠、亮黄绿、温润棕木、青蓝水面，少量珊瑚花；叶面有受控高光而非塑料镜面。
- 光照 / 氛围：树冠之外明亮，棋盘接受软天光；斑驳光和前景叶不得遮住格边与目标。
- 机制启发：藤路、生长桥或一次性扎根；用小关卡先解释变化何时触发，以及是否可恢复。

## 5. 右方：重庆式现代山城

### 来源要点
- 重庆市政府介绍主城区位于长江、嘉陵江交汇区域，山水与城市空间相互穿插；山城不仅是高楼天际线。
- 洪崖洞资料强调依崖层叠的吊脚楼和巴渝建筑特征。现代山城还需交通、住宅、台地和河岸组成层次，不能把洪崖洞等同整座重庆。
- 山地高差使“同一水平位置”可能属于不同街道高度；本项目把这种体验转译成可读的立体空间，不复刻实际建筑或街道。
- 来源：[重庆市政府：Geography](https://english.cq.gov.cn/aboutchongqing/overview/Geography/)；[重庆市政府：Hongyadong](https://english.cq.gov.cn/specials/explore/PhotoPerfectSpots/202608/t20260810_15912600.html)；[中国政府网：城市地貌与建筑](https://english.www.gov.cn/news/202410/27/content_WS671e1affc6d0868f4e8ec5a8.html)。

### 原创转译
- 结构：阶梯状地台、错层入口、细长架空轨道、桥墩、不同高低的住宅盒子、外楼梯与屋顶露台。高楼设在背面，不能挡棋盘。
- 材质 / 色彩：奶油混凝土、陶红砖、雾蓝玻璃、青绿交通设施和柠檬色标识。选雨后明朗黄昏，不套用泛滥的紫红赛博霓虹。
- 光照 / 氛围：金色侧光和偏青远山、河面；高差靠明暗与护栏辨识，不靠大量浓雾。
- 机制启发：电梯、换层或定向运输，让路线的高低关系有逻辑意义。若最终规则为单层，应保留外围的立体交通景观，并明确不宣称实现真实多层寻路。

## 6. 制作验收用研究结论

- 同一主角、倒角尺度、接触阴影强度、目标符号与箱子辨识体系贯穿四界。
- 每界至少有一眼可辨的建筑轮廓、一组独有的材质色、一种特有环境动势，而不是同一个棋盘换背景色。
- 实机按实际游玩尺寸检查：角色、可推物、目标、障碍、专属机关五类必须能直接区分；装饰不能伪装可交互物。
- Blender 预览与 Godot 实机各自验证。预览好看不能代替游戏镜头中的清晰度，头部测试通过也不能代替视觉自评。
- 只保留本项目原创模型、材质、动画、声音与脚本；研究页仅存要点与来源链接。
