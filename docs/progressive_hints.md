# 渐进提示

提示是可选辅助，不改变关卡、分数、撤销、解锁或存档格式。

## 玩家操作
1. 按 **H** 或底栏「线索」：只读一个机制提醒。
2. 主动按 **J** 或「看看下一推」：从**现在的局面**寻找下一步。金圈标箱子、箭头标一次推动，不会执行它。
3. 再按 **J** 或「显示到位路线」：薄荷线仅通往推动前的站位，不含推动。想继续解题，自己操作即可，旧提示自动消失。

H / Esc /「收起线索」关闭；移动、撤销、重置、换关、离开棋盘或打开帮助都会取消旧提示。无倒计时、无费用。

- **达到搜索上限**：本次额度用尽，不等于无解。先尝试别的走法，再请求也可以。
- **已确认无法全部归位**：求解器已经证明当前局面不可能完成，可以自行撤销；不会自动重置。
- **已经完成**：不再显示箱子或路线。

## 技术契约

冻结求解器原始SHA256：`f266da3bb93226cbb68c3077d8481d637411ea0da81d508016ec431c443ddbe9`。生产 `scripts/hint_solver.gd` 与该文件一致。

`main.gd` 只使用当前player/crates快照。每帧活动搜索或退休回收共用 `step_budget(2.0)`，默认8000累计节点。每个显示结果都须同时匹配请求号和当前棋局签名。主场景保留单solver实例，正常退出先取消并等待回收。

提示面板和标记分别由 `main.gd` / `hint_overlay.gd` 负责。路线上没有自动调用移动函数。未加载任何开局答案或Python；`tests/solver_report.json`仅供离线测试。
