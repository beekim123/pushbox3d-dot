# 四隅织途 · Loom of Four Horizons

## V2 方向修正
用户已否定 V1 建模效果。北方以蟠桃园为准，不再制作宫殿主景；旧的金框棋盘、等距重复摆件和简单椭球石块不再是质量标准。研究详见 research_v2.md，制作范围详见 REVISION_V2.md。

## 研究之后的原创方向
参考来源及事实见 research.md。我们借鉴的是高斜角的棋盘可读性、精致的建筑边饰和跨世界统一尺度，不复制任何关卡、角色、音乐或界面。原创视觉概念：一套被四季拆散的陶木机械玩具，由携带线轴的邮差重新织合。

## 全局造型与渲染
- 场景逻辑网格边长 2 米，模型以底部中心为原点。棋盘嵌入连续地貌；外沿曲岸、层岩、植被有高低层次。格线仅帮助读题，不把每格做成金框盒子。拒绝三角面灰模、随机噪声和重复小球堆。
- 材质是釉陶、彩漆木、哑光黄铜。共用暖象牙、深靛蓝以及少量黄铜交互细节，粗糙度有层次；有色表面而非贴图拼接。
- 所有 3D 模型、材质与角色动作均在 Blender 制作并以 GLB 导入；保留 .blend 和生成脚本。运行时只布置、移动和播放既有资源。
- 高斜角正交镜头，视线下方留出可玩地面。边缘建筑强调世界深度，不遮挡箱子、目标和路径。光照以柔和主光、天空填充和清楚的接触阴影为主。
- 玩法标志以形状和颜色双编码：目标为环形凹座，传送为成对漩涡，滑行有纹带，根门有方向箭头，压力桥有机械横梁及开闭反馈。
- UI 采用原创新月/线轴意象的圆角深色小面板、暖白文字、世界色强调。不是网页表格。中文使用系统字体，无外部字体文件。
- 角色：线轴邮差，象牙色圆身体、靛蓝短披肩、黄铜线轴背包、两条短缎带。待机、步行、推动、庆祝为 Blender 中独立动作。

## 北 · 蟠桃仙园
调色板：树干深赤褐 #5B3640、花阴影 #C76A8C、中间花色 #F3A4B5、亮瓣 #FFE3D4、水 #448F92、叶苔 #548C70、园径暖白 #E8DBC0。
主景为扭转、渐细、非对称分枝的桃树，花簇沿枝生长，大小花带之间保留能看穿的空间；不能用粉色球冠代替。仙桃有纵沟、凹口与短叶。宽展主树、偏侧中树与稀疏幼树必须具有不同骨架。
连续苔地、月牙仙池、曲岸和不规则层岩构成地貌。低荷叶与立叶分组，保留空水面。石块有倾向、切面和深槽，不是灰色土豆；苔只局部覆盖上表面。
套件：旧石园径、苔石障碍、自然地貌底盘、木篮织箱、桃花目标、三种桃树、池岸荷花、花果精灵、风纹滑行格。
镜头中的主树不得被 HUD 裁切，也不得遮挡合法棋格。池水与可滑行机关使用不同符号和边界。
机制：风纹地面使箱子沿推动方向滑行；角色不滑行。

## 南 · 烛糖地牢
调色板：紫梅 #675087、珊瑚 #EB7868、杏 #FFD092、煤蓝 #313653、黄铜 #CBA06A。
厚拱门、短石柱、卷角炉、圆煤块；没有血腥元素。地下空间仍色彩明快，暖炉火与冷紫边缘分离。
套件：拼砌厚石地面与墙体、由楔石组成的圆拱、曲管锅炉、火渠/热池和断续曲岸、炉箱、炉环目标、圆煤灵、成对传送泉眼。不用单根紫色半圆管冒充地牢。
机制：箱子进入一端泉眼，出现在另一端；出口被占则推不动。

## 西 · 回声雨林
调色板：碧绿 #329C82、嫩叶 #9ECD67、湖青 #55C4BC、花珊瑚 #F18D8A、土 #986B56。
树冠、林下和地面三层构图；板根树、阔叶和花簇有成组形状，不以随机粒子填满。水与林缘为边框，不误导可走区域。
套件：木苔地面、板根墙、曲溪岸、种子箱、花环目标、分枝板根大树、多层厚弯叶与林下花丛、种子精灵、单向根门。近景叶有厚度、中折和弯曲，不是平纸片。
机制：根门只允许按箭头方向进入，玩家和箱子遵守同样规则。

## 东 · 层桥山城
调色板：湖蓝 #4D9AA8、赭黄 #E6B562、珊瑚 #DD7D68、奶白 #F0DDC2、河靛 #3C5875。
重庆启发来自山河高差、层叠街面、吊脚支撑、高架和楼群，不照搬具体地标。背景楼体有阳台、窗洞、屋顶、阶梯和桥梁；谜题操作平面清晰，景观高差不伪装可走路径。
套件：街面、矮墙、错层地基、运输箱、站点目标、阶梯楼群、大小屋顶露台与阳台、坡道高架、桥墩河岸、缆车精灵、压力踏板与升桥。先做好楼群之间的空间关系，不靠重复同一楼体凑城市。
机制：箱子压住任意踏板时桥门打开；不能形成玩家或箱子被关闭桥门占住的状态。

## 中心与交汇
中心为自然石台上的四向织机庭院，北仙园、南地窖、西雨林、东都市。线轴、共同倒角和黄铜边饰统一四个世界。完成四地后回到织机进入交汇试炼，以两种已学机制组合，不突然增加新规则。

## 自评标准
每个世界至少 Blender 渲染一张、Godot 两张。检查：一眼识别主题；游戏尺度箱子/目标明确；装饰不挡解谜；轮廓和材质精致；无灰模；UI 不遮棋盘；所有截图为实际输出，不冒称风格已获用户验收。

## 规模与性能
每个世界 50 关采用 5 套人工构图模板，配合章节变换主景侧向、疏密与前后层次，不随机散点。花/叶/建筑静态细部在 Blender 按材质合并，运行时只实例化导入网格。保留压缩 .blend 与完整源脚本，避免为装饰制造数千 draw call。
