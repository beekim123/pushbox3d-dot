# V2 独立验收审查：蟠桃仙园与四方五十关

日期：2026-10-23。状态：制作与最终验证进行中。本报告不覆盖 V1 的 acceptance_audit.md，也不把 V1 的 16 关、字体或场景检查计数当作 V2 结果。

## 本轮范围
每方向 10 章 × 5 关，共 200 主线，另 4 个交汇奖励关。美术改为蟠桃园及重新制作的四方自然场景。审查重点为真实算法、关卡多样性、存档安全与界面行为；美术主观验收和图形实机由主任务完成。

## 宏推动搜索初审
- `solve_macro` 的状态保留精确玩家坐标和箱子集合，没有将玩家位置错误合并为可达区；单向根门下尤其重要。
- 每次宏动作先在真实规则下 BFS 最短不推箱路径，然后执行一次推动；Dijkstra 代价是（推动次数，移动步数），因此保持原来的精确字典序目标。
- 放宽死格分析允许桥门全开、忽略单向箭头、允许滑道各前缀停靠、传送既可跳转也可原地停留；只增加可能性，因此不把真实可解状态误剪成死格。
- 实际差分测试：320 个固定种子的小型混合机制棋盘、首批 20 关，以及原有 16 个复杂回归棋盘，宏搜索与未剪枝基础逐步 Dijkstra 的可解性与最少推动/同推动最少步数全部一致。旧关卡只作为算法回归，不算 V2 内容完成数。
- 可复现：`python -m unittest discover -s tests -p test_macro_independent_v2.py -v`。此命令包含 320 随机实例与当前前 20 个样本；旧 16 关差分是另外实际执行的历史回归。

## 已发现的真实问题与整改
1. 首批雨林第 02、04 关，即使禁止使用箭头，仍可用完全相同的推动数和步数通关。机关只是某条等价走法偶然经过，不能称为有意义的教学。已要求替换，筛选不再因“第一章”放行同代价旁路。
2. 章节 `stage_intent` 原本为固定模板，不能据此证明每关真的需要“借位”“留路”。已要求从实际解答轨迹导出可核对的策略提示。
3. 部分首章骨架相同，仅机关位置有变化；完整 D4 指纹虽不重复，仍要求首批教学关避免依靠这种方式填数量。跨世界相同骨架但不同规则并不自动等于重复。
4. 原迁移实现未检查 V1 备份复制失败就覆盖原文件；已有同名不同内容备份也直接跳过。已要求先逐字确认备份，重名另存，失败只读；未知未来版本不能自动降级覆盖。
