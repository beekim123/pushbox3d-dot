# 四隅织途 · pushbox3d-dot

原创 Godot 4.7.2 三维推箱解谜项目。全部模型、材质和模型动画由 Blender 原创生成并以 GLB 导入；音乐和音效由源脚本合成。

## 当前阶段

正在迁入既有工程并完成 V2：蟠桃仙园美术重制、四个方向各 50 道主线关卡、4 道交汇奖励关，以及分章节旅程选关。初始提交仅建立仓库和开发检查点，尚不是完整可运行迁入版。

后续按可检查阶段持续提交，保留历史；通过测试的功能与美术和未完成项会分别记录。不会将代码测试通过等同于玩家审美验收。

## 开发原则

- 原创资产、原创关卡，不使用现成游戏素材。
- 无限撤销，重置本身也可撤销。
- 关卡必须经过求解与规则回放验证，不以镜像/旋转改名凑数。
- 每阶段记录实际测试、截图和已知问题，再同步仓库。
- Godot 工程、Blender 源文件、生成脚本和设计文档将一起迁入。
