## 已实际覆盖的行为

- 首次胜利逻辑已提交、tween 尚未结束时，Right→R→Z 恢复精确局面与历史，并立即登记一次成绩、给出下一关；原 tween/缓冲不复活。
- 已登记的 win→R→Z 连续三轮：精确局面、计数、历史、成绩不变；恢复结算不重复调用进度保存、win 音效或启动 celebrate 动画。R/Z 自身音效照常调用。
- 胜利后 F1、重复 F1，以 Esc 或真实鼠标“明白了”返回正确结算；不改棋局、历史或成绩。
- 直接 Esc 可以收起结算；连续普通行走不会每步重弹。显式再开/关帮助可以返回当前结算。较差步数不会覆盖最佳成绩。
- 实际 U→D→R 的 3 步首次成绩，再重置后 1 步真重玩：已 solved ID 仍可改善最佳成绩。撤销赢步再同成绩重赢正常反馈，但不重复写不变的 best。
- 赢局 tween 中提前打开/关闭帮助：原 tween 保留，旧缓冲丢弃；tween 结束不再次替换已显示结果，也不复活被主动 Esc 关闭的结果。
- 八个方向键/WASD 在帮助→结算→再关闭后仍遵守原 held-key guard；松开并同帧重按不吞动作。R/Z 是有意操作，不恢复过时结算。
- 新关、不同世界、hub、title 保留旧 level 对象时不泄露旧结算；普通帮助不凭缓存已赢状态在非棋局上重开结果。

## 计数的含义

`spy.gd` 是继承生产 main 的**只计数子类**，场景在进入树前换成该子类；仅覆盖 `save_progress`、`sfx` 计数并调用 `super`，没有替代任何输入、历史、完成、UI 或规则处理器。celebrate 计数来自真实 `AnimationPlayer.animation_started` 信号。

QA 模式跳过主进度文件写入，所以“保存次数”是**生产保存方法调用次数**，不是磁盘耐久提交次数；真实续玩 sidecar 另行完成磁盘往返。没有把 headless 音效调用当作人工听感验收。
