## 运行

完整获取工程后，用 **Godot 4.7.2** 打开根目录 `project.godot`，等待导入，按 **F5**。

- 运行不需要 Blender、Python、FFmpeg、外部字体或网络。
- `.blend` 源目录有 `.gdignore`；Godot 直接导入已提供的 GLB，无需设置 Blender 路径。
- 源文件与生成脚本保留，重建美术需要 Blender 4.3.2 或兼容版本；重建音频需要脚本声明的 Python 依赖及 FFmpeg。这些不是游玩的前置步骤。

## 游戏

你扮演线轴邮差，从中心织机庭院连接四方：

| 方位 | 世界 | 主要风貌 | 谜题规则 |
|---|---|---|---|
| 上 | 蟠桃仙园 | 分枝桃树、桃花、仙池、苔石云岸 | 箱子在风纹格滑行，角色不滑 |
| 下 | 烛糖地牢 | 厚石拱、曲铜管锅炉、暖火渠 | 配对焰环传送箱子，出口需空闲 |
| 左 | 回声雨林 | 板根、厚弯叶、藤蔓、曲溪 | 根门仅允许沿箭头方向进入 |
| 右 | 层桥山城 | 错层楼群、坡道高架、桥墩河岸 | 箱子压板开启桥门 |

每方向 **10 章 × 5 关 = 50 关**，合计 **200 主线**；之后有 **4 道双机制交汇奖励关**，共 204 关。章节由引导、取位、借箱、窄颈、环路、双室逐步到三箱调度。每章选关只显示五个旅程节点，可回访已经解锁的谜题。

- 方向键 / WASD：移动与推动；只能推一个箱子，不能拉。
- Z / Backspace：无限撤销。
- R：重置，**重置本身也可撤销**。
- F1：帮助；棋局内附本章练习，少量关卡给观察问题，不直接揭示路线。关闭帮助后，原先按住的方向键需松开再按。Esc：优先收起线索、关闭弹窗或返回；M：声音；F2：高/轻画质。
- H：打开/收起可选线索；J：主动展开下一层。先给机制提醒，再提示下一只箱子的一个推动，最后才可选择显示到位路线；从不自动移动。
- 单次按键有立即响应，动画中允许缓冲一个动作，不积压长串输入。
- 标题可选「继续此前保存」：恢复局面与完整撤销，包括可撤销重置。停手后节流保存；退出失败会明确列出此前记录，可返回游戏或仍退出。8192条上限只限制磁盘续玩，不截断游戏内undo；异常旧档保留只读。详见 `docs/resume.md`。
- 自动保存进度和最佳成绩。V1 存档在验证归档成功后才开启 V2 新旅程，保留声音设置；不覆盖未知未来版本或备份失败的旧档。

## 原创与源文件

所有模型、材质和模型动画均由本项目在 Blender 中制作，导出 GLB。没有下载或复用现成模型、贴图、角色、关卡、字体或采样音频。

`assets/models/` 为运行资产；`blender/` 为压缩 .blend 与生成脚本。音乐、环境声、音效由 `tools/generate_audio.py` 原创合成；长循环使用 Ogg Vorbis，短音效使用 WAV。图片只出现在自己渲染的验收截图中，不是运行贴图。

## 已知边界

- 目前验证环境是云端 Linux，macOS/硬件 GPU/Retina/手柄尚未实测。
- 云端 CPU 软件渲染不代表真实 GPU；自动轻量档只是兼容性回退，不承诺 60 FPS。
- 谜题的可解性、规范去重和最优代价经过机器检查，尚无真人盲测，不能等同于每道都已验证趣味。
- 中庭为可点击的四向地图；山城高差主要表现于景观，棋盘仍是单层规则，不冒称多层重力系统。
